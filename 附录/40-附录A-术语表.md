## 40.2 二、参数与公式速查

### 关键参数

| 参数 | 经验值 |
| --- | --- |
| 分块大小 | 中文 300–500 字 |
| 分块重叠 | 50–100 字（10–20%） |
| 向量召回 Top-K | 30–50 |
| BM25 召回 Top-K | 30–50 |
| 重排输入 | 20–50 |
| 送入生成 | 3–5 |
| RRF 常数 k | 60 |
| 拒答阈值（相关性分） | 0.3 左右（需实测） |
| temperature（事实问答） | 0–0.3 |
| temperature（创意） | 0.7–1.0 |
| top_p | 0.8–0.95 |
| HNSW M | 16–32 |
| HNSW efConstruction | 200 |
| HNSW efSearch | 64–128 |
| BM25 k1 / b | 1.2–2.0 / 0.75 |
| 显存安全余量 | 15–20% |
| Agent 最大轮次 | 6 |
| 端到端 P95 目标 | ≤ 3 秒 |

### 核心公式

```text
单次成本 = 输入Token × 输入单价 + 输出Token × 输出单价
月成本   = 日请求数 × 30 × 单次成本

RRF 分数 = Σ 1 / (k + rank_i)      k = 60

显存 ≈ 权重 + KV Cache + 运行时开销(1–2GB)
权重 = 参数量 × 每参数字节（FP16=2, INT8=1, INT4≈0.5）
KV Cache = 2 × 层数 × KV头数 × 头维度 × 序列长度 × 并发 × 字节

卡数 = 峰值并发 ÷ 单卡可承载并发 × 1.3

私有化划算条件：公有云年费 > 私有化年成本 × 1.3
静态回收期 = 项目投入 ÷ 年净收益
```

### 换算

| 换算 | 值 |
| --- | --- |
| 1 汉字 | ≈ 1 Token |
| 1000 Token | ≈ 750 英文单词 |
| 1 页 A4 中文 | ≈ 800–1000 Token |
| 7B FP16 / INT8 / INT4 | 14 / 7 / 4 GB |
| 14B FP16 | 28 GB |
| 70B FP16 | 140 GB |

## 40.3 三、四张可直接用的清单

### 清单 1：需求调研（27 问，见 [17 章](../第五篇-方案与商务/17-解决方案设计与售前.md#172-需求调研清单（可直接打印带去客户现场）)）

打印带去客户现场，边问边勾。

### 清单 2：POC 验收

- [ ] 范围：一个部门 / 一类文档 / 20–50 个高频问题
- [ ] 数据：客户真实数据（脱敏），不使用演示数据
- [ ] 指标：准确率、溯源率、P95 延迟、拒答正确率、越权次数
- [ ] 评测集：50–100 条，含标准答案与应命中块
- [ ] 周期：4–6 周，明确里程碑
- [ ] 退出机制：不达标即停，书面确认
- [ ] 结项：POC 报告 + 客户签字

### 清单 3：上线前检查（Go-Live Checklist）

**效果**
- [ ] 评测集全部跑过，核心指标达标且无回退
- [ ] 拒答策略生效（越界问题测试通过）
- [ ] 引用可点开、可核对

**安全**
- [ ] 多角色交叉测试，无越权
- [ ] 提示注入测试（文档埋指令）未触发
- [ ] 敏感信息测试（问手机号/薪酬）已拒答
- [ ] 工具权限最小化，写操作需确认

**性能**
- [ ] 峰值并发压测，P95 达标
- [ ] 降级演练通过（断模型 → FAQ/人工）
- [ ] 限流与超时配置生效

**合规**
- [ ] 数据来源合法性确认
- [ ] 个人信息脱敏完成
- [ ] 内容安全过滤生效
- [ ] 生成内容标识已添加
- [ ] 算法备案（如适用）已完成
- [ ] 日志留存与审计可查

**运维**
- [ ] 监控告警接入（效果/性能/资源/成本）
- [ ] 回滚方案演练
- [ ] 值班与响应机制明确

### 清单 4：交付移交

- [ ] 架构文档、部署文档、接口文档
- [ ] 提示词与配置（版本号、变更记录）
- [ ] 索引重建脚本与操作手册
- [ ] 评测集与评测脚本
- [ ] 监控看板与告警规则
- [ ] 账号、密钥、证书移交（安全渠道）
- [ ] 培训记录（管理员 / 运营 / 最终用户）
- [ ] 运维交接会议纪要 + 责任人

> 客户会上听到不认识的词，**不要装懂，直接问「您说的 X 是指哪一种口径」**。
> 追问口径不丢人，用错口径才丢人——尤其「验收基线」「SLA」「偏离」这三个词，理解错会直接影响合同。
